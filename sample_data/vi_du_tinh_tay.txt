VÍ DỤ TÍNH TAY HỆ MÃ BA LÔ MHK
(Đối chiếu với chương trình: menu chính mục 3 rồi mục 7; menu tấn công mục 1 rồi mục 6, 7, 8)

======================================================================
VÍ DỤ 1 (BTVD1): GIẢI BÀI TOÁN XẾP BA LÔ SIÊU TĂNG
======================================================================
A = (3, 5, 10, 20, 45), M = 60. Tìm X = (x1 x2 x3 x4 x5) sao cho tổng xi*ai = 60.

Kiểm tra A siêu tăng: 5 > 3; 10 > 3+5 = 8; 20 > 3+5+10 = 18; 45 > 3+5+10+20 = 38.

Duyệt từ phần tử lớn nhất, so sánh với GIÁ TRỊ CÒN LẠI C (không phải M):
  C = 60 >= 45  ->  x5 = 1, C = 60 - 45 = 15
  C = 15 <  20  ->  x4 = 0
  C = 15 >= 10  ->  x3 = 1, C = 15 - 10 = 5
  C =  5 >=  5  ->  x2 = 1, C = 5 - 5 = 0
  C =  0 <   3  ->  x1 = 0
C = 0 nên bài toán có nghiệm: X = (0 1 1 0 1).
Kiểm tra: 5 + 10 + 45 = 60.

======================================================================
VÍ DỤ 2 (BTVD2): SINH KHOÁ, MÃ HOÁ, GIẢI MÃ
======================================================================
Tham số: A' = (2, 3, 6, 12, 25), N = 5, M = 53, u = 46. Bản rõ P = 01001.

BƯỚC 0. KIỂM TRA ĐIỀU KIỆN
- A' siêu tăng: 3 > 2; 6 > 2+3 = 5; 12 > 2+3+6 = 11; 25 > 2+3+6+12 = 23.
- M lớn hơn tổng A': 53 > 2+3+6+12+25 = 48.
  (Điều kiện M > 2*a'5 = 50 trong slide cũng thoả: 53 > 50.)
- gcd(46, 53) = 1, vì 53 là số nguyên tố.

BƯỚC 1. SINH KHOÁ
Khoá công khai S = (a'i * u) mod M:
  s1 = (2 * 46) mod 53  =   92 mod 53 = 39
  s2 = (3 * 46) mod 53  =  138 mod 53 = 32
  s3 = (6 * 46) mod 53  =  276 mod 53 = 11
  s4 = (12 * 46) mod 53 =  552 mod 53 = 22
  s5 = (25 * 46) mod 53 = 1150 mod 53 = 37
=> Kp = (S, M) = ((39, 32, 11, 22, 37), 53)

Tìm u^-1 (nghịch đảo của 46 theo modulo 53) bằng Euclid mở rộng:
  53 = 1*46 + 7
  46 = 6*7  + 4
   7 = 1*4  + 3
   4 = 1*3  + 1
Thế ngược:
  1 = 4 - 3 = 4 - (7 - 4) = 2*4 - 7
    = 2*(46 - 6*7) - 7 = 2*46 - 13*7
    = 2*46 - 13*(53 - 46) = 15*46 - 13*53
=> u^-1 = 15. Kiểm tra: 46 * 15 = 690 = 13*53 + 1.

Khoá riêng: Ks = (A', u, u^-1, M) = ((2,3,6,12,25), 46, 15, 53)
(Giải mã cần cả A', nên khoá riêng gồm A' chứ không chỉ (u, u^-1).)

BƯỚC 2. MÃ HOÁ P = 01001 (x1=0, x2=1, x3=0, x4=0, x5=1)
  C = (0*39 + 1*32 + 0*11 + 0*22 + 1*37) mod 53
    = 69 mod 53
    = 16

BƯỚC 3. GIẢI MÃ
  C' = C * u^-1 mod M = 16 * 15 mod 53 = 240 mod 53 = 28   (240 = 4*53 + 28)
Giải ba lô siêu tăng với A' = (2, 3, 6, 12, 25), đích C' = 28:
  28 >= 25  ->  x5 = 1, còn 3
   3 <  12  ->  x4 = 0
   3 <   6  ->  x3 = 0
   3 >=  3  ->  x2 = 1, còn 0
   0 <   2  ->  x1 = 0
=> P = 01001, trùng bản rõ ban đầu. Kiểm tra chéo: 3 + 25 = 28 = C'.

======================================================================
VÍ DỤ 3: MÃ HOÁ CHUỖI "NEU" (5 BIT MỖI KÝ TỰ)
======================================================================
Quy ước do nhóm tự đặt cho ví dụ: A = 0, B = 1, ..., Z = 25, mỗi chữ 5 bit,
mỗi chữ là một khối N = 5. Dùng khoá ở ví dụ 2: S = (39,32,11,22,37), M = 53, u^-1 = 15.

  Chữ  Số  Bit     C                                   C' = C*15 mod 53   Giải ba lô
  N    13  01101   (32 + 11 + 37) mod 53 = 27          27*15 = 405 -> 34   34 = 3+6+25 -> 01101
  E     4  00100   11 mod 53 = 11                      11*15 = 165 -> 6    6 = 6        -> 00100
  U    20  10100   (39 + 11) mod 53 = 50               50*15 = 750 -> 8    8 = 2+6      -> 10100

=> Bản mã của "NEU" là (27, 11, 50).

Lưu ý: chương trình mã hoá theo BYTE (8 bit/ký tự) với khoá ngẫu nhiên, nên khi mã hoá
chính tệp này, bản mã sẽ KHÁC các số ở trên. Ví dụ 3 minh hoạ nguyên lý theo ghi chú
cuối slide, còn ví dụ 2 được tái hiện chính xác ở menu chính (mục 3 rồi mục 7).
